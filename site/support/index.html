Setup and troubleshooting

Know what the renderer needs.

Highlight Studio controls proprietary hardware through access you provide. Most setup issues come from the access method stopping after a reboot.

Start with compatibility.

Use Pixel 11 Pro, Pixel 11 Pro XL, or Pixel 11 Pro Fold running Android 17. Other devices and Android versions are not supported by this release.

  1. 01

    Choose an access method

    Approve Shizuku, start the ADB helper, or approve your existing root manager. Highlight Studio does not install or enable these tools for you.

  2. 02

    Grant only the rules you use

    Notification access is needed for notification rules. Usage access is needed for while-open rules. Microphone and camera activity rules observe Android's active state and do not capture media.

  3. 03

    Restart access after reboot

    Shizuku and the ADB helper do not survive a normal reboot. Restore your chosen method, reopen Highlight Studio, and confirm the Live screen reports a ready renderer.

  4. 04

    Stop an unexpected light safely

    Turn Live off, wait for automatic cleanup, then use Retry LED cleanup in Setup. The retry sends black states only and does not flash colours.

Still seeing a problem?

Use Copy LED diagnostics in Setup before restarting anything. The allowlisted report excludes notification content, accounts, device identifiers, package names, and logcat.
