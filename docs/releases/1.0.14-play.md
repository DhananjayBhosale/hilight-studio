## Changes

This update improves root startup reliability and adds configurable notification reminders, private
rule backup/import, optional app-icon colours, grouped independent rules, and a finite battery-level
gauge. Existing light-safety limits and the Play distribution boundary remain in place.

## Verified gates

- GitHub flavor: 367 unit tests; Play flavor: 369 unit tests. No failures, errors, or skips.
- GitHub and Play release builds passed. Release lint passed with zero errors (58 GitHub warnings
  and 60 Play warnings).
- The signed APK and AAB use the expected permanent certificate. The APK passed 16 KiB native-library
  alignment verification.
- The signed Play APK is `com.highlight.studio` version `1.0.14` code `15`.
- Packaged permissions are limited to Usage access, foreground-service and special-use foreground
  service, notifications, boot completion, Shizuku, Android's generated dynamic-receiver
  permission, and Google Play's `com.android.vending.CHECK_LICENSE` permission. Neither `INTERNET`
  nor `QUERY_ALL_PACKAGES` is present.
- The packaged app contains the ADB helper, Shizuku user-service entry point, and official Google Play
  in-app update code. It contains no GitHub updater class or GitHub release URL.
- The `specialUse` service manifest property explains that it monitors foreground apps and device
  orientation for user-configured HiLight rules.

## Play Console submission

- Existing track retained: **Closed testing - Alpha**, with 14 (1.0.13) previously available to
  selected testers in 177 countries/regions.
- The previously uploaded version-code 15 bundle was selected from Play's artifact library and
  submitted as release `15 (1.0.14)` at 100% of the existing Alpha audience.
- Device Catalog targeting was verified after submission preparation: only Google Pixel 11 Pro
  (`grizzly`), Pixel 11 Pro XL (`kodiak`), and Pixel 11 Pro Fold (`yogi`) remain supported. The
  other 37 currently compatible device models are manually excluded.
- Publishing overview shows **Changes in review**. Play's automated quick checks are still running;
  Google states that the change will be sent for review when those checks complete successfully.
  Managed publishing remains off.
- The only release warning is that the bundle contains native code without uploaded native debug
  symbols. This is non-blocking; the bundle includes its ReTrace mapping file.
- App content showed no declarations needing attention. Completed declarations included the
  `FOREGROUND_SERVICE_SPECIAL_USE` permission, no collected/shared data, no advertising ID, no ads,
  18-and-over target age, no restricted sign-in, and the live privacy policy at
  `https://hilightstudio.dhananjaytech.app/privacy/`.

## Remaining verification limits

No physical supported Pixel was attached for this release. The signed GitHub 1.0.13-to-1.0.14
emulator upgrade retained 22 preference entries and launched, but an emulator is not physical LED,
Shizuku, ADB, root, or Play-delivery proof. KernelSU recovery, the reported stuck-LED scenario,
recording-only detection, and physical battery impact remain unverified. Deep sleep may delay
notification reminders. Import uses a bounded synchronous preference commit, and existing grouped
rules may display in stored priority order.
